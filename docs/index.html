Credit Card Fraud Detection with Explainable AI

Using XGBoost and SHAP to detect fraudulent transactions and explain model predictions.

About Our Project

Our project explores credit card fraud detection using machine learning. We compared multiple models and selected XGBoost as our final model. We also use SHAP Explainable AI to show how different transaction features influence each prediction.

Model Performance

Our final XGBoost model achieved the following results:

Accuracy

99.53%

Precision

57.89%

Recall

66.76%

F1 Score

62.00%
